# AI 口播智能体（可运行的第一版）

Windows 10/11 桌面程序，包含素材导入、中文语音识别、可选 AI 改写、中文在线配音、SRT 字幕生成和 MP4 合成流程。

## 当前具备的功能
- 导入本地视频，或尝试使用 yt-dlp 获取公开可访问的视频 URL（平台限制、登录、地区和版权设置可能导致失败）。
- 使用 faster-whisper 识别中文口播。首次运行需要下载识别模型；默认 CPU int8，RTX 显卡可在自行配置 CUDA 环境后通过环境变量 `AI_KOUBO_WHISPER_CUDA=1` 尝试启用 GPU。
- 使用 OpenAI 兼容的 Chat Completions API 改写文案（需自己配置服务与密钥）；不配置时可手动编辑。
- 使用 edge-tts 在线生成中文配音（需要联网）。
- 生成 SRT 字幕文件并用 FFmpeg 合成 MP4，背景视频循环播放至配音结束。
- 将输出文件保存在本机用户目录下的 `.ai_koubo_agent/work`；API 设置保存在本机 `.ai_koubo_agent/settings.json`，不会自动上传到 GitHub。

## 安装与运行
1. 安装 Python 3.11。
2. 解压仓库 ZIP。
3. 双击 `setup.bat`，等待依赖安装完成。
4. 双击 `run.bat` 启动。

## AI 改写配置
在软件设置区填写：
- **OpenAI 兼容 API 地址**：例如服务的 API 根地址（通常以 `/v1` 结尾），不要填入密钥。
- **模型名称**：你的服务实际支持的模型 ID。
- **API Key**：服务提供的密钥。

点击“AI 改写文案”。请先确认服务商的价格、隐私条款和可用性。密钥会以本地设置文件形式保存，请仅在个人电脑使用并保护好 Windows 账户。

## 重要限制
- 字幕时间目前按每行固定时长估算，和真实语音节奏不一定同步，导出后需要复核。
- 在线 TTS 依赖网络和第三方服务可用性；它不是声音克隆。
- 当前版本没有完成照片驱动数字人、精确口型同步、动作迁移、自动发布到抖音/小红书等功能。这些需要额外的数字人模型/服务、平台授权及独立测试。
- 视频网址下载并非保证成功。仅处理自己拥有或获授权的素材，遵守平台服务条款、版权和肖像权规定。
- 目前只提供自动构建 EXE 的 GitHub Actions 工作流；只有在 Actions 显示成功并生成 Artifact 后，才表示云端打包成功。不要把当前源码状态误认为已经完成所有功能或经过 Windows 实机完整验收。
