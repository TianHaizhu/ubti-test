# AI 口播智能体（第一版）

这是一个 Windows 11 桌面端项目骨架，使用 PySide6 构建界面。当前版本提供素材选择、文案编辑、流程状态展示和导出路径选择；尚未接入真实的抖音下载、云端大模型、语音克隆或数字人口型模型。

## 当前功能
- 选择本地视频、照片和音频素材
- 输入/编辑原始文案与改写文案
- 展示处理流程状态
- 选择 MP4 输出路径（当前为界面骨架，尚不会合成视频）
- 为后续集成 FFmpeg、语音识别、TTS、数字人服务预留扩展位置

## 环境
- Windows 10/11
- Python 3.11（推荐）
- NVIDIA RTX 3050 4GB / 16GB RAM：可运行界面；大型数字人模型通常建议使用云端服务或轻量模型

## 运行
1. 安装 Python 3.11，并勾选 **Add Python to PATH**。
2. 解压项目，双击 `setup.bat` 安装依赖。
3. 双击 `run.bat` 启动程序。

也可以在终端执行：
```powershell
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install --upgrade pip
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

## 规划中的后续模块
1. 取得有权处理的视频素材（优先官方接口或用户本地文件）
2. ASR 提取口播文本
3. 大模型改写（需用户自行配置 API 服务及密钥）
4. 中文 TTS / 经本人授权的声音克隆
5. 使用本人授权照片或视频驱动数字人并同步口型
6. FFmpeg 合成字幕与 MP4
7. 发布到平台时优先使用官方 API，并在发布前让用户确认

## 重要说明
- 本仓库不是已完成的全自动生产系统；第一版是可运行的桌面 UI 骨架。
- 不要把 API 密钥写入源码或提交到 GitHub。后续应使用本地环境变量或安全配置。
- 仅处理自己拥有或获得授权的素材；遵守抖音、小红书等平台的服务条款、版权和肖像权要求。
